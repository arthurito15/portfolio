Building this site with AI — and why I’m writing here

Building in public AI Data Science

I’ve always thought a portfolio should be more than a collection of projects.

A GitHub repository can show the code. A CV can show the experience. But neither really shows how you think, how you learn, or how you approach problems.

That’s one of the reasons I decided to build this website.

Why a personal website?

As a Data Science student, I’m constantly working on different things: machine learning models, data analysis, Power BI dashboards, APIs, databases, cloud technologies, and sometimes completely new tools that I’ve never used before.

Over time, I realized that simply listing these technologies wasn’t enough.

I wanted one place where I could show the projects I’ve built, explain the decisions behind them, document what I’m learning, and share things that might be useful to other students and developers.

So this website became more than a portfolio.

It became a place to document the journey.

Building it with AI

One of the interesting parts of building this website was using AI throughout the process.

I didn’t ask AI to simply generate a website and copy-paste the result.

Instead, I treated it more like a development partner.

I used AI to explore ideas, improve sections of the design, debug code, rewrite content, and think through different approaches. I still had to make decisions about the structure, the technologies, the visual identity, and what I actually wanted the website to communicate.

AI can generate code very quickly, but generating code isn’t the same thing as building something good.

You still need to understand what you’re building.

Learning by building

This website also reflects something I’ve learned during my studies:

The best way to learn a technology is often to build something with it.

Instead of waiting until I feel completely ready, I’ve started taking a more practical approach.

Learn the fundamentals.

Build something.

Break it.

Debug it.

Improve it.

Then build something slightly more difficult.

That cycle has helped me understand technologies much better than simply following tutorials from beginning to end.

What you’ll find here

I’ll use this blog to document different parts of my journey in Data Science and technology.

Some posts will be technical. Others will be about projects, tools, career development, or lessons I’ve learned along the way.

Expect posts about things such as:

  • Machine Learning projects and experiments
  • Data analysis and visualization
  • Power BI dashboards
  • Python and SQL
  • MLOps and cloud technologies
  • Data engineering
  • AI and RAG systems
  • Projects I’m building
  • Things that didn’t work
  • Lessons learned along the way

What’s next?

I’m currently building my skills across Data Science, Machine Learning, Data Engineering and Cloud technologies.

My goal isn’t to know everything.

It’s to keep building, keep learning, and become better at solving real problems with data and technology.

This website is my way of documenting that process.

So, welcome.

This is where I build, learn, experiment, and share.

And hopefully, some of what I learn along the way will be useful to you too.
